# 2026년 7월 개선 작업 회고

기존 IMPROVEMENT_PLAN.md와 PHASE5_PLAN.md의 결과를 2026-09-05에 통합했다.
이 문서는 과거 결정과 검증의 기록이다. 현재 작업 지침은 [AGENTS.md](../../AGENTS.md)에 있다.

## 반영된 결과

- 공유 타입·IPC 채널과 타입 지정 호출 helper를 도입했다.
- CI에 타입 검사·커버리지·프로덕션 빌드 검증을 반영했다.
- Repository가 저장 예약을 소유하고, 복합 mutation은 트랜잭션으로 처리하게 했다.
- sql.js 스냅샷 저장을 직렬화하고 임시 파일 교체와 종료 flush를 구현했다.
- MCP 도구를 도메인별로 나누고 JobsView의 위자드·상태 UI를 컴포넌트로 분리했다.
- v1.0.0에서 기본 Bearer 인증과 토큰 관리, CLI 설정 갱신, Codex 환경변수 등록 안내를 추가했다.
- 후속 v1.0.1 작업에서 workflow import 경계와 IPC 검증, 핵심 커버리지·릴리스 정합성을 보강했다.

## 보류된 결정

better-sqlite3 전환은 당시 측정에서 합의한 성능 개선을 충족하지 못해 보류했다.
Electron 네이티브 빌드와 기존 SQLite 파일 호환성은 확인했지만, 전환 이득은 별개였다.
환경·측정값·한계는 [스파이크 보고서](../spike-better-sqlite3.md)에 남아 있다.
이 결과는 당시 환경에 한정되며, 재검토 여부는 새로운 성능 문제와 측정 근거로 판단할 수 있다.

## 폐기한 계획과 검증 기록의 해석

- rename 실패 시 원본 DB에 직접 쓰는 fallback 제안은 채택하지 않았다.
  현재 저장 경로는 임시 파일을 교체하며 재시도 소진 시 실패를 전파한다.
- 과거 단계별 승인 게이트, 파일 줄 수 제한, 테스트 무수정 요구와 미확정 버전 계획은 종료했다.
- 초기 기록에는 focused test 84개와 컴포넌트 테스트 4개 통과, 전체 검증의 spawn EPERM 중단이
  남아 있었다. 후속 [v1.0.1 작업 기록](../../work/consistency-hardening-progress.md)에는
  당시 전체 검증 통과가 기록되어 있다. 어느 쪽도 현재 checkout의 검증 결과를 뜻하지 않는다.

이후 변경은 [CHANGELOG.md](../../CHANGELOG.md)와 날짜가 명시된 작업·감사 기록에서 확인한다.
